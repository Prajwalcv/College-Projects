This Contiguous Memory Allocation project uses First fit Algorithm to simulate the memory allocation done by Operating System. 
It keeps a track of holes(available chunks of memory) using holes table and continuously updates it whenever the memory is allocated for a process.
It searches and allocates the first hole that is big enough hence reducing the time required for memory allocation.

Note: This project is a simulation of memory allocation only and does not include deallocation functionality as it is more complex and beyond the scope of this simulation.
